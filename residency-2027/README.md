## 1. 지금 내 위치 진단

레포에서 확인되는 작업만 놓고 보면:

| 강점 | 약점 / 확인 필요 |
|---|---|
| 8개월간 10개 이상의 프로토타입을 만든 꾸준한 실험량 | 레포에 **전시 이력·학력·수상 기록이 없음** → 국내 공모 상당수가 "최근 3년 개인전 1회 또는 단체전 3회" 또는 **예술활동증명**을 요구 |
| 카메라 기반 감지(객체 인식·스켈레톤·사람 트래킹), 웹오디오 합성, GPU 파티클, 위치 기반 공동 드로잉을 **직접 코딩** | 대부분 "브라우저 프로토타입" 단계 → 공간 설치로 완성된 작품 기록(설치 사진·영상)이 부족할 수 있음 |
| `인기척` → `PRESENCE SYNTH`로 이어지는 일관된 주제(기계가 사람의 기척을 감지하는 방식) | 대학(원) 재학·휴학생이면 산양·금천은 지원 불가 |
| 관객 참여형 작업(Geo Ink, Ink Body World) → 지역 주민 프로그램으로 바로 확장 가능 | |

**결론:** 국립·대형 레지던시(MMCA 고양·창동, 난지)보다는 **지역 레지던시, 리서치 트랙, 미디어아트 특화 해외 펠로십** 쪽이 승산이 높습니다. 특히 "체험 프로그램 운영", "리서치" 같은 조건이 붙은 곳은 참여형·코딩 기반 작업이 오히려 강점이 됩니다.

## 4. 제출 전 체크리스트

- [ ] **자격 확인**: 최근 3년 개인전 1회 / 단체전 3회 이상 **또는 예술활동증명(시각예술)** 보유? (산양 필수) — 없으면 예술활동증명부터 신청(발급까지 시간이 걸리므로 홍티 리서치·Kala를 우선)
- [ ] 대학(원) 재학·휴학 중이 아닌지 (산양·금천 제외 대상)
- [ ] NCAS(www.ncas.or.kr) / SCAS(www.scas.kr) 회원가입 및 본인인증 **오늘 미리** 완료
- [ ] 각 기관 **지정 서식** 다운로드 → 아래 문서 내용을 서식에 옮겨 붙이기 (분량 제한에 맞춰 줄이기)
- [ ] `[대괄호]` 로 표시된 개인정보·이력 채우기 (레포에 없어서 비워둠 — **임의로 지어내지 않았습니다**)
- [ ] 포트폴리오 PDF: 각 작품별 **스크린 녹화 영상 링크** + 스틸 3–4장 (`00_공통자료.md` 의 구성안 참고)
- [ ] GitHub Pages 등으로 작품을 **실제 체험 가능한 URL** 로 공개 → 포트폴리오에 QR/링크 첨부
- [ ] 홍티와 산양 둘 다 NCAS 접수 → 마감 당일 서버 혼잡 대비, **11/29까지 제출**
