## 1. 지금 내 위치 진단

> 이 레포의 웹 실험 기록에, **다른 Claude 세션 대화**(개인전 인쇄물 제작, moteus 모터 제어)에서 확인한 정보를 더했어요.

| 강점 | 약점 / 확인 필요 |
|---|---|
| **첫 개인전** 《사람 없는 사물들의 아침》 (빈.방, 서울, 2026.11.27–12.11): 키네틱·사운드·인터랙티브 신작 4점 + 영상 2점 | 개인전이 **마감 직전(11/27)에 열림** → '최근 3년 개인전 1회' 실적으로 인정되는지 확인 필요 |
| **해외 공연 연출**: La MaMa Spoleto Open Festival(2025, 이탈리아), CultureHub(2026, 뉴욕) | 시각예술 **단체전 이력**과 학력은 세션 기록에서 찾지 못함 |
| 연극·인형 → 로보틱스·인터랙티브로 이어지는 뚜렷한 서사: "사물은 배우다" | 대학(원) 재학·휴학 중이면 산양·금천 지원 불가 |
| 기술을 직접 다룸: 서보·BLDC 모터(moteus, 사이클로이드 감속기), 3D 스캔·프린팅, 객체 인식, 웹오디오 | 빈.방이 '개인 작업실'로 볼 수 있으면 금천 지원 불가 |
| 비어 있던 상가를 고쳐 공간(빈.방)을 직접 만들고, 동네 산책 체험까지 운영한 경험 → 지역 레지던시와 잘 맞음 | 개인전 기록 영상·사진을 아직 확보 중 |

**결론:** 생각보다 경쟁력이 높아요. 지역 레지던시(산양, 홍티)는 **창작 분야로 충분히 승부할 수 있고**, 해외 공연 경력 덕분에 Kala나 홍티 국제 분야도 해볼 만해요. 국립 레지던시(MMCA 고양, 난지)는 개인전 기록을 정리한 뒤 2027년 가을 공고 때 1순위로 노리세요.
